# Release Plan

## Connected Vehicle Telemetry Platform

### Current Internal Target

Engineering is planning toward technical production readiness on September 30.

This date reflects the latest estimates for performance validation, certificate provisioning integration, and production monitoring.

### Key Milestones

- August 15 — Certificate provisioning integration complete
- August 22 — End-to-end authentication testing complete
- September 5 — Full-scale performance testing complete
- September 16 — Production monitoring complete
- September 23 — Production-readiness review
- September 30 — Technical production readiness

### Launch Criteria

Production launch requires:

- Successful end-to-end vehicle authentication
- Demonstrated peak throughput
- Production monitoring and alerting
- Successful multi-availability-zone failover test
- Completion of the production-readiness review

### Customer Alignment

The September 30 technical readiness target is currently an internal planning date.

The customer-facing production commitment has not yet been formally updated.
