# ai-automation-lab

Razvan's AI Automation Lab.

This repository documents my hands-on learning journey into AI engineering and automation. The goal is to move beyond using AI as an end user and build a practical understanding of how LLM-based systems work — from APIs, tokenization, embeddings and attention to function calling, RAG, agents, guardrails and MCP.

My focus is on connecting these concepts to real-world problems, particularly how AI can improve technical program and delivery management through automation, better access to information, and earlier identification of risks, dependencies and inconsistencies. The repository contains small experiments and progressively more complete projects as I learn and apply these concepts.
